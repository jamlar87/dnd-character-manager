# Multiclassing Implementation Plan (PHB 2014)

> **Goal:** Add full PHB 2014 multiclassing support — level into any class, prerequisites enforced, spell slots combined per multiclass table, features tracked per-class, HD/HP split by class.

**Architecture:** Store class levels as JSON dict `{"Fighter": 5, "Wizard": 3}`. Keep `class_name` as "primary" (first class) for backward compat. Add `class_levels` column. Every function currently taking `class_name: str` gets a parallel path that reads `class_levels`. Spell slots use the PHB multiclass caster table. Warlock stays separate.

**Risk:** High. Touches ~30 functions, DB schema, creation wizard, level-up wizard, character sheet, spells, features, audit. Must not break existing single-class characters.

## RESEARCH: PHB Rules Verification

Before writing any code, verify every rule against PHB 2014 p.163-165:

| Rule | PHB Page | Details |
|------|----------|---------|
| Prerequisites | p.163 | Both current AND new class minimums (table: Barb 13 STR, Bard 13 CHA, Cleric 13 WIS, Druid 13 WIS, Fighter 13 STR or 13 DEX, Monk 13 DEX + 13 WIS, Pal 13 STR + 13 CHA, Ranger 13 DEX + 13 WIS, Rogue 13 DEX, Sorc 13 CHA, Warlock 13 CHA, Wizard 13 INT) |
| Proficiencies | p.164 | Table: limited weapons/armor/skills. NO save profs. NO skill profs from class list (except Ranger/Rogue/Bard get 1 from class list) |
| HD & HP | p.163 | Track HD per class. HP at level-up = roll/average new class HD + CON mod |
| Spell Slots | p.165 | Table: full casters add full level, half add floor(level/2), third (EK/AT) add floor(level/3). Warlock Pact Magic separate |
| Spells Known/Prepared | p.164 | Determined per-class individually (L5 wizard with L3 cleric prepares as L5 wiz AND L3 cleric separately) |
| Channel Divinity | p.164 | Gain options from new class, but uses DON'T stack |
| Extra Attack | p.164 | No stacking. Fighter gets 3rd at L11, 4th at L20 — those are Fighter class features, not Extra Attack stacks |
| Unarmored Defense | p.164 | Only first version gained applies |
| ASI | p.163 | Class-level based. Fighter gets at 4,6,8,12,14,16,19. Rogue at 4,8,10,12,16,19. Others at 4,8,12,16,19 |
| Cantrip Scaling | p.164 | Based on CHARACTER level, not class level |
| PB | p.163 | Based on CHARACTER level (total level) |

## PHASE 1: Database Migration (non-breaking)

### Task 1: Add class_levels column
- **File:** `main.py:140-181` (init_db)
- Add: `class_levels TEXT DEFAULT '{}'` (JSON string) to characters table
- Backfill existing characters: `UPDATE characters SET class_levels = json_object(class_name, level)` in migration step
- Keep `class_name` and `level` columns — `class_name` becomes "primary/first class", `level` becomes total character level
- Migration runs in `init_db` via `ALTER TABLE ... ADD COLUMN` (SQLite supports)

### Task 2: Add multiclass helper functions
- **File:** `main.py` (new section after RACES/CLASSES)
- `MULTICLASS_PREREQS: dict` — 12 entries mapping class_name → required abilities + minimums
- `MULTICLASS_PROFICIENCIES: dict` — class_name → {weapons, armor, skills, tools} gained when multiclassing INTO
- `parse_class_levels(row) -> dict` — parse `class_levels` JSON, fall back to `{class_name: level}` for old chars
- `total_level(class_levels) -> int` — sum of all class levels
- `class_for_feature(class_levels, feature_name) -> str` — which class provides this feature

### Task 3: Spell slot multiclass table
- **File:** `main.py`
- `MULTICLASS_SPELL_SLOTS: dict[int, list[int]]` — PHB p.165 table, keyed by "caster level" → [1st, 2nd, ..., 9th]
- `compute_multiclass_caster_level(class_levels) -> int` — sum full caster levels + floor(half/2) + floor(third/3)
- `get_multiclass_spell_slots(class_levels) -> dict` — returns same shape as get_spell_slots
- Pact Magic (Warlock) slots ALWAYS separate — never combined

## Open Questions

1. **Spells Known casters:** Bard 4 / Sorcerer 3 — Bard knows 7 spells (L4 Bard), Sorc knows 4 spells (L3 Sorc). Track separately or merge? PHB says separate. Implementation: separate spell lists per class on Spells tab.

2. **Warlock + normal caster:** Warlock 3 / Sorcerer 3 → Pact Magic: 2 L2 slots. Normal slots: caster level 3 (4/2). Can convert Pact slots to Sorcery Points? Yes per PHB. Track both pools.

3. **Delete class_levels column if multiclass unused?** No — simpler to always store it. Single-class: `{"Fighter": 5}`. Multiclass: `{"Fighter": 3, "Wizard": 2}`.

4. **Level-down multiclass?** Initially no — level-down only removes from last class added. Full respec = recreate character.
